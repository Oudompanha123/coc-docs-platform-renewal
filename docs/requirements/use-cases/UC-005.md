# Use Case UC-005: Read a documentation page

> **REQ-ID**: UC-005
> **Version**: 1.0
> **Preceding Document**: [REQUIREMENTS-SPEC.md](../REQUIREMENTS-SPEC.md)

> The read path is the part users already have and already like. **The measure of success here is that nothing gets worse.**

---

## 1. Scenario Overview

| Item | Description |
|------|------|
| **Primary User** | `user` — an internal developer |
| **Secondary** | `guest` — defined in the role model, **not enforced in MVP** (phase 2) |
| **Preconditions** | Signed in with sufficient role for the requested page |
| **Trigger** | Someone needs to know how to do something |
| **Outcome (Success)** | The published page renders in the chosen language, quickly |
| **Outcome (Failure)** | Styled 404, or a clear access-denied — never a stack trace or a blank page |
| **Related FR** | FR-READ-001, 002, 003, 004, 005, 006 · FR-AUTH-005, 006 · FR-NAV-005 |
| **Related NFR** | NFR-PERF-01, NFR-AVAIL-01, NFR-AVAIL-02, NFR-COMPAT-01, NFR-SEC-CHANNEL, NFR-SEC-PII |
| **Related BR** | BR-004, BR-009, BR-016 |

## 2. Main Flow

| Step | Actor | Action | System Response |
|------|------|------|------------|
| 1 | `user` | Requests a page URL | Session checked (**FR-AUTH-005**); role compared with the page minimum role (**FR-AUTH-006**) |
| 2 | System | — | Published version for the requested locale retrieved |
| 3 | System | — | Blocks rendered, including embedded components and copyable code blocks |
| 4 | System | — | Navigation rendered from the database (**FR-NAV-005**) |
| 5 | `user` | Reads the page | Delivered **P95 < 1s** (**NFR-PERF-01**) |
| 6 | `user` | Switches language | Lands on the equivalent page, not the section root (**FR-READ-005**) |

## 3. Alternative Flow

### 3.1 A-1: Arrive via a legacy hash URL (**FR-READ-002**)
- Action: an old `/#faq`-style bookmark is opened
- Outcome: redirected to the current path. Old bookmarks keep working — a hard requirement, not a nicety (`LegacyHashRedirect.tsx:11-21`)

### 3.2 A-2: Arrive via a renamed slug (**FR-READ-003**)
- Action: an external link points at a slug an admin has since changed
- Outcome: permanent redirect to the new path

### 3.3 A-3: Requested language not translated (**FR-READ-006**)
- Action: page exists in `en` only
- Outcome: visible notice plus a link to the English version. Generalises today's hand-built per-page `PendingTranslation` component into a system behaviour

### 3.4 A-4: Page is stale in this language (**FR-I18N-004**)
- Outcome: **renders normally.** Staleness is an editorial signal shown in the admin console, never a reader-facing degradation

## 4. Exception Flow

### 4.1 E-1: Insufficient role
- Occurs at Step 1. Action: access denied and logged (**FR-OPS-002**). Outcome: page existence is not revealed to an unauthorised reader.

### 4.2 E-2: Page missing, unpublished, or deleted (**FR-READ-004**)
- Action: styled 404 inside the normal layout, with navigation still usable

### 4.3 E-3: Database unavailable (**NFR-AVAIL-02**)
- Action: serve the cached rendering of published pages
- Outcome: **readers keep reading during a backend outage.** This exists because it is a real regression — today's pages are pre-rendered and survive the backend entirely; once pages are database-backed the database becomes a single point of failure for reading

### 4.4 E-4: Embedded component fails to render
- Action: the component's area degrades to a placeholder; the rest of the page still renders
- Outcome: one broken Tier B embed never takes down a whole page

## 5. Non-Functional Requirements Mapping

| NFR-ID | Application |
