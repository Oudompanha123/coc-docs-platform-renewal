# Use Case UC-001: Edit an existing page and publish it

> **REQ-ID**: UC-001
> **Version**: 1.0
> **Preceding Document**: [REQUIREMENTS-SPEC.md](../REQUIREMENTS-SPEC.md)

> **This is the use case the project exists for.** If UC-001 works and everything else fails, the business problem is solved. If UC-001 fails, nothing else matters.

---

## 1. Scenario Overview

| Item | Description |
|------|------|
| **Primary User** | `admin` — a non-technical colleague (writer, PM, or domain owner) |
| **Preconditions** | Signed in with Google; holds the `admin` role; the page already exists |
| **Trigger** | A documentation page contains something wrong or out of date |
| **Outcome (Success)** | The corrected page is live for readers. **No developer was involved, no code changed, no deploy ran.** |
| **Outcome (Failure)** | The edit is not lost; the editor is told why it could not be saved or published |
| **Related FR** | FR-CONT-001, 002, 003, 004, 005, 011, 012, 013 · FR-I18N-002 · FR-OPS-001 |
| **Related NFR** | NFR-USE-01, NFR-USE-02, NFR-PERF-02, NFR-PERF-03, NFR-SEC-SANITIZE, NFR-OPS-AUDIT, NFR-OPS-VERSION, NFR-COMPAT-02, NFR-SCALE-01 |
| **Related BR** | BR-005, BR-006, BR-010, BR-023, BR-024 |

## 2. Main Flow

| Step | Actor | Action | System Response |
|------|------|------|------------|
| 1 | `admin` | Opens the admin console | Signed-in dashboard; recent edits and translation status shown |
| 2 | `admin` | Finds the page (list, filtered by section / language) | Page list with status: Published · Draft · Stale translation |
| 3 | `admin` | Clicks the page | Editor opens with the current published content loaded as editable blocks (**NFR-PERF-03: P95 < 2s**) |
| 4 | `admin` | Edits text in a block | Change applied in the editor. No markup, no code (**FR-CONT-002, NFR-USE-02**) |
| 5 | `admin` | Clicks **Save draft** | Draft stored. Published version is **unchanged and still live** (**FR-CONT-003**, NFR-PERF-02: P95 < 2s) |
| 6 | `admin` | Clicks **Preview** | Draft rendered exactly as readers will see it (**FR-CONT-004**) |
| 7 | `admin` | Clicks **Publish** | Content sanitised (**NFR-SEC-SANITIZE**), version snapshot written (**FR-CONT-012**), page goes live **with no build and no deploy** (**FR-CONT-005**) |
| 8 | System | — | Audit entry recorded: actor, action, target, timestamp (**FR-OPS-001**) |
| 9 | System | — | If the edited version was `en`, km and ko are marked **stale** but remain published (**FR-I18N-002, FR-I18N-004**) |
| 10 | Reader | Loads the page | Sees the new content (**NFR-PERF-01: P95 < 1s**) |

## 3. Alternative Flow

### 3.1 A-1: Abandon the draft
- Branches at Step 5 or 6
- Action: `admin` discards the draft
- Outcome: Draft deleted; the published version was never affected

### 3.2 A-2: Edit a non-reference language
- Branches at Step 3 — `admin` selects the km or ko version
- Action: Edit and publish that language only (**FR-I18N-005**)
- Outcome: Other languages untouched; **no staleness is propagated** — staleness flows only from `en`

### 3.3 A-3: Revert to a previous version
- Branches at Step 3
- Action: `admin` opens version history and restores an earlier version (**FR-CONT-012**)
- Outcome: The restored content becomes the current draft, to be previewed and published as normal

### 3.4 A-4: Insert a copyable code block
- Branches at Step 4
- Action: `admin` inserts a code block from the block menu (**FR-CONT-011**)
- Outcome: Block retains its copy affordance for readers — it is a distinct type, not preformatted text

## 4. Exception Flow

### 4.1 E-1: Concurrent edit (**FR-CONT-013**)
- Occurs at Step 5 or 7
- Condition: Another `admin` saved this page after this editor opened it
- Action: Save is refused; the editor is shown who changed it and when, and offered *keep mine* / *take theirs* / *open a comparison*
- Outcome: **No silent overwrite.** The editor's work is never discarded without an explicit choice

### 4.2 E-2: Sanitisation rejects content (**NFR-SEC-SANITIZE**)
- Occurs at Step 7
- Condition: The body contains markup that would execute
- Action: Publish blocked; the offending block is identified in plain language
- Outcome: Draft preserved; nothing unsafe reaches readers

### 4.3 E-3: Session expired
- Occurs at any step
- Action: On save, re-authenticate via Google; the draft is preserved through the round trip
- Outcome: No work lost. *(Depends on NFR-SEC-SESSION — blocked on AMB-006, the AS-IS 1-day vs 30-day contradiction)*

### 4.4 E-4: Database unavailable
- Occurs at Step 5 or 7
- Action: Save fails with a clear message; the editor is told the content is still in the browser and to retry
- Outcome: Reader pages continue to serve from cache (**NFR-AVAIL-02**)

### 4.5 E-5: Insufficient role
- Occurs at Step 1 or 3
- Condition: The signed-in user holds `user`, not `admin`
- Action: Editor is not reachable; attempt is logged (**FR-OPS-002**)
- Outcome: Denied server-side, not merely hidden in the UI (**FR-AUTH-005**)

## 5. Non-Functional Requirements Mapping

| NFR-ID | Application |
|--------|------|
| **NFR-USE-01** | **The entire flow, Steps 1–7, performed by a non-technical colleague unaided, with no help beyond a one-page guide. Pass = completed without asking the PM.** |
| NFR-USE-02 | No step requires TypeScript, JSX, Markdown, HTML, git or deployment knowledge |
| NFR-PERF-02 | Step 5 and Step 7 complete P95 < 2s |
| NFR-PERF-03 | Step 3 editor interactive P95 < 2s |
| NFR-SEC-SANITIZE | Applied at Step 7 before content is persisted as published |
| NFR-OPS-AUDIT | Step 8 entry retained ≥ 1 year, append-only |
| NFR-OPS-VERSION | Step 7 snapshot; ≥ 20 versions retained |
| NFR-COMPAT-02 | Flow works on current Chrome and Edge, desktop |

## 7. Test Scenarios

| Test ID | Case | Input | Expected Result |
|-----------|--------|------|---------|
| TC-001-01 | Happy path | Edit text → save draft → preview → publish | Page live; published version changed only at publish |
| TC-001-02 | Draft isolation | Save draft, do not publish | Reader still sees the **old** content |
| TC-001-03 | No deploy | Publish | **Zero builds triggered** — the project KPI |
| TC-001-04 | Concurrent edit | Two admins, same page, both save | Second is warned; neither edit silently lost |
| TC-001-05 | Sanitisation | Paste `<script>` into a block | Publish blocked, block identified, draft kept |
| TC-001-06 | Staleness | Publish an `en` edit | km and ko marked stale, both still readable |
| TC-001-07 | Version restore | Restore version N-1 | Prior content returns as a draft |
| TC-001-08 | Role denial | `user` opens the editor URL directly | Denied server-side and logged |
| TC-001-09 | **Usability** | **Non-technical colleague, one-page guide, no help** | **Publishes successfully without asking the PM (NFR-USE-01)** |
| TC-001-10 | Session expiry | Session lapses mid-edit, then save | Re-auth prompted; draft preserved |
