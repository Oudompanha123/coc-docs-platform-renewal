Setup guide

Get the dashboard reporting real numbers.

Five steps — from installing the reporter script to seeing your team's daily Claude usage live on the dashboard.

ℹ You need admin or super_admin role to complete steps 1 and 4. Any team member can complete steps 2 and 3 on their own machine.
1
Copy your ingest secret
In the admin panel, open Claude Usage → Configuration. Copy the Ingest Secret shown there. This is the bearer token the reporter script uses to submit daily numbers — keep it out of version control.
✔ Admin only
2
Download the reporter script
Save the script to a folder on your machine. It reads from the Claude Code local usage log and POST the day's token totals to the platform.
# Download the reporter (one-time) curl -o ~/scripts/report-claude-usage.sh \ https://platform.coc.internal/scripts/report-claude-usage.sh chmod +x ~/scripts/report-claude-usage.sh
3
Configure and run it once
Set the two required environment variables and do a manual run to confirm data reaches the dashboard before automating.
export COC_INGEST_URL="https://platform.coc.internal/api/ingest" export COC_INGEST_SECRET="paste-your-secret-here" # Run once manually ~/scripts/report-claude-usage.sh
Reported 2026-09-18: input=148320 output=41200 cache_read=0 cost_usd=0.0891 OK
If you see OK, your numbers are live. If you see an error, check that the secret matches what is shown in Configuration.
⚠ Verify OK before continuing
4
Schedule it to run daily
Add a cron job that fires once a day — end of day works best so the numbers are complete. The script is idempotent: running it twice on the same day overwrites (not doubles) the row.
# Open crontab crontab -e # Add this line (runs at 23:30 every day) 30 23 * * * COC_INGEST_URL="..." COC_INGEST_SECRET="..." ~/scripts/report-claude-usage.sh
✔ One-time setup per machine
5
Invite team members to the dashboard
Go to Claude Usage → Members and click Invite teammate. Enter their email address (must match the one Claude Code uses on their machine). Once invited, their next daily report will flip their status from Invited to Active automatically.
You can also set a per-member weekly token budget at invite time, or adjust it later from the Budget overrides panel.
✔ Done — check back tomorrow for data

The script reports the full running total for the day on each run. If your machine was off, it will catch up on the next run. Historical days already reported are never deleted, even if you are later removed from the roster.

Configuration

Manage your team's usage settings.

Everything you can configure on the Claude Usage dashboard — roles, budgets, the ingest secret, and reporting periods.

Roles
The Usage dashboard has its own two-level role system, independent of your platform role.
👑
Admin admin
Can do everything a member can, plus:
  • Invite and remove team members from the roster
  • Set or clear individual budget overrides
  • View the ingest secret in Configuration
  • Export usage reports to XLSX / ZIP
Who should be admin? Team leads and whoever manages Claude Code licences.
👤
Member member
Can view the usage table and chart for the current period. Cannot see other people's individual token breakdown unless they are on the roster themselves.
Budget overrides
The dashboard shows each member's usage against a weekly token budget. You can set a team-wide default and override it per person.
💰
Team default budget
Set in Configuration → Default weekly budget. Applies to every member who does not have a personal override. Displayed as a progress bar on the chart — green below 80%, amber 80–100%, red above.
⚙
Per-member override
Open Budget overrides panel, find the member, enter a token count. Leave blank to revert to the team default. The override scales automatically when switching between Day / Week / Month views so the comparison always makes sense.
Ingest secret
The shared bearer token that reporter scripts use to submit daily usage data.
🔑
Rotating the secret
If the secret is compromised, click Rotate secret in Configuration. A new secret is generated immediately. All reporter scripts using the old secret will start failing — update their environment variable before the next scheduled run. There is no grace period.

Do not commit the secret to version control. Pass it as an environment variable or store it in your machine's keychain.
Reporting period
The period selector (Day / Week / Month) controls which rows are summed for the usage table and chart.
📅
How period scaling works
  • Day — shows today's totals vs. 1/7 of the weekly budget.
  • Week — shows this calendar week vs. the full weekly budget.
  • Month — shows this calendar month vs. 4× the weekly budget.

Per-member budget overrides use the same multiplier, so switching periods never changes whether someone appears over or under budget relative to their allocation.
